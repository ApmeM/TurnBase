# TurnBase.KaNoBu.Godot

## Краткое описание

Это графическая клиентская и серверная реализация KaNoBu для Godot. Папка содержит сцены, UI-элементы, уровни, клиент/серверную коммуникацию, перехват событий, логирование в Godot и набор готовых компонентов для игровой презентации.

## Какого типа классы и файлы она должна содержать

Эта папка должна содержать:
- графические сцены и логические классы, связаные с интерфейсом игры (`Presentation/`);
- прокладку между Godot и игровым движком (`Client`, `Server`, сериализация обмена);
- уровни и игровые поля (`Level*`, `GameField`, `Unit`, `WaveGenerator`);
- компоненты UI и расширения Godot (`gd-*` и `gd-utils`);
- адаптеры для локальной/сетевой игры, логгирования и игровых событий;
- специальные правила уровней, если нужен отдельный игровой сценарий поверх стандартных правил KaNoBu.

Здесь должно быть всё, что относится к визуализации, интерактивной игре и сетевому слою, но не базовая логика KaNoBu как такая.

## Роль и устройство

Проект `TurnBase.KaNoBu.Godot` — это оболочка вокруг ядра игры для запуска в Godot. Он объединяет:
- `TurnBase` как базовый движок;
- `TurnBase.KaNoBu` как игровую механику;
- Godot-слой как графический интерфейс и взаимодействие с пользователем.

Основные блоки:
- `Presentation/` — игровые сцены, уровни, логика меню, старты уровней, настройки и старт игры;
- `Client` / `Server` — сетевой слой для взаимодействия с удалённым сервером и передачи команд/ответов;
- `KaNoBuRulesPredefinedFieldWithShips` — специализированные правила для уровней Godot, которые оборачивают базовый `KaNoBuRules`;
- `gd-*` — готовые reusable Godot-компоненты (анимации, попапы, таймер, инвентарь, указатели, HUD и т.д.);
- `addons/` — плагины и дополнительные ресурсы для редактора Godot.

Графический проект должен использовать базовую игровую логику как сервис, а не дублировать её. Новая механика обычно описывается в `TurnBase.KaNoBu` или `TurnBase`, а её визуальная часть — в Godot-презентации. Это разделение помогает безопасно менять UI и игровые правила независимо.

Также важно помнить, что Godot-проект содержит не только обычный UI, но и сетевой слой, сериализацию сообщений и список действий для клиента/сервера. Это значит, что любые изменения в коммуникационном протоколе должны быть согласованы с `TurnBase` и `TurnBase.KaNoBu`.
