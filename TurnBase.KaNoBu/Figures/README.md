# Figures

## Краткое описание

Папка содержит модели фигур KaNoBu и их правила поведения. Здесь описаны все типы кораблей/фигур, их идентификаторы, логика движения, логика побед/поражений в бою и преобразование типа фигуры.

## Роль и устройство

Файлы этой папки описывают доменную сущность `Фигура` типа `KaNoBuFigure` и ее вариации. Система KaNoBu использует абстрактный класс `KaNoBuFigure`, который реализует интерфейс `IFigure` из общего игрового движка. При изменении поведения фигуры сначала следует определить, относится ли оно к самой фигуре, общим правилам боя или отображению, и править соответствующий слой.

Фигуры в этой папке — не графические объекты, а логические игровые сущности с правилами конфликта между типами. Визуальное представление и сценарии игры должны обращаться к этим классам, а не дублировать их правила.

## Типы фигур

Все конкретные классы фигур должны наследоваться от класса `KaNoBuFigure` и переопределять его абстрактное свойство `FigureType` и абстрактные методы `IsMoveable`, `IsMoveValid` и `ResolveBattle`.

Новые типы фигур должны быть добавлены в:
- перечисление `FigureTypes` в `KaNoBuFigure`;
- метод `Create` в `KaNoBuFigure`;
- логику побед/поражений в `KaNoBuRules` и в `KaNoBuFieldMemorization`, если используются скрытые/открытые состояния;
- способ краткого и полного отображения в `FigureTypeInfo.PrintableName`.

### `KaNoBuFigure`

**Назначение:** базовая абстракция, описывающая фигуры KaNoBu поверх абстракции игрового движка IFigure. Содержит базовые поля и абстрактные методы для переопределения конкретными реализациями фигур.

**Ключевые особенности:** 

Хранит базовую информацию о фигуре: 
- владелец `PlayerId`, 
- тип конкретной фигуры из перечисления `FigureType`, 
- количество одержанных побед `WinNumber`, 
- информация о видимости другим игрокам `VisibleForAllPlayers`;

Содержит абстрактные методы работы с классом:
- определяет, может ли фигура двигаться (`IsMoveable`);
- проверяет допустимость хода (`IsMoveValid`);
- вычисляет результат боя фигуры (атакующий) с переданным кораблем (защитник) (`ResolveBattle`). Возвращённая атакующая фигура означает победу атакующего, возвращённый защитник — победу защитника, `null` — ничью. При победе результат дополнительно обрабатывается `KaNoBuRules`: фигура может быть удалена, получить победу или преобразоваться в универсальную.;

Поддерживать безопасное копирование для клиента (`CopyForPlayer`).

### `ShipFlagKaNoBuFigure`

**Описание:** `Флаг` игрока, самая важная фигура, которую требуется защищать. Флаг не атакует соседние фигуры, поскольку не может двигаться, но может быть атакован. При захвате флага `KaNoBuRules` передаёт оставшиеся фигуры проигравшего под контроль победителя.

**Движение:** не может двигаться (`IsMoveable = false`); любой `MoveStep` недопустим.

**Результат боя в роли атакующего:**
- при защитнике типа `Unknown` выбрасывает исключение `Can not resolve battle with unknown ship`;
- при любом другом известном типе защитника (`ShipFlag`, `ShipStone`, `ShipPaper`, `ShipScissors`, `ShipUniversal`, `ShipMine`, `ShipScout`) выбрасывает исключение `Flag can not initialize battle`;
- для неподдерживаемого значения `FigureTypes` выбрасывает исключение `Unsupported figure type {figureType}`.

### `ShipMineKaNoBuFigure`

**Описание:** неподвижная `Мина`, уничтожающая нападающую фигуру. Когда мина является защитником, `ResolveBattle` возвращает мину как победителя, после чего `KaNoBuRules` удаляет победившую мину с поля. В уведомлении боя устанавливается признак `isMine`.

**Движение:** не может двигаться (`IsMoveable = false`); любой `MoveStep` недопустим.

**Результат боя в роли атакующего:**
- при защитнике типа `Unknown` выбрасывает исключение `Can not resolve battle with unknown ship`;
- при любом другом известном типе защитника (`ShipFlag`, `ShipStone`, `ShipPaper`, `ShipScissors`, `ShipUniversal`, `ShipMine`, `ShipScout`) выбрасывает исключение `Mine can not initialize battle`;
- для неподдерживаемого значения `FigureTypes` выбрасывает исключение `Unsupported figure type {figureType}`.

### `ShipStoneKaNoBuFigure`

**Назначение:** основная боевая фигура типа `Камень`.

**Движение:** метод `IsMoveValid` через `Point.IsAdjacentTo` разрешает только соседнюю клетку по горизонтали или вертикали и запрещает `From == To`. Диагональное и удалённое перемещение не допускается. Границы поля, стены, владельца фигуры и занятость цели дополнительно проверяет `KaNoBuRules`. Поэтому одного результата `IsMoveValid` недостаточно для полной проверки хода.

**Результат боя в роли атакующего:**
- при защитнике типа `Unknown` выбрасывает исключение `Can not resolve battle with unknown ship`;
- побеждает `Ножницы` и `Флаг`;
- проигрывает `Бумага`, `Мина`, `Универсал` (который после победы меняет тип на `Бумага`);
- против любой другой фигуры ничья

### `ShipUniversalKaNoBuFigure`

**Назначение:** усиленная универсальная фигура, в которую боевая фигура типа `Камень`, `Ножницы` и `Бумага`,  преобразуется после трёх побед.

**Движение:** метод `IsMoveValid` через `Point.IsAdjacentTo` разрешает только соседнюю клетку по горизонтали или вертикали и запрещает `From == To`. Диагональное и удалённое перемещение не допускается. Границы поля, стены, владельца фигуры и занятость цели дополнительно проверяет `KaNoBuRules`. Поэтому одного результата `IsMoveValid` недостаточно для полной проверки хода.

**Результат боя в роли атакующего:**
- при защитнике типа `Unknown` выбрасывает исключение `Can not resolve battle with unknown ship`;
- побеждает `Флаг`;
- против `Камень` атакующий получает тип `Бумага` и побеждает;
- против `Ножницы` атакующий получает тип `Камень` и побеждает;
- против `Бумага` атакующий получает тип `Ножницы` и побеждает;
- проигрывает `Мина`;
- против `Универсал` — ничья;
- против `Скаут` атакующий получает тип `Скаут` и побеждает;

### `ShipScoutKaNoBuFigure`

**Назначение:** подвижная фигура, которая побеждает только флаг.

**Движение:** метод `IsMoveValid` разрешает перемещение на расстояние от одной до двух клеток по Манхэттену. Перемещение на большее расстояние, в ту же клетку или по диагональной траектории с Manhattan distance больше двух не допускается. Границы поля, стены, владельца фигуры и занятость цели дополнительно проверяет `KaNoBuRules`.

**Результат боя в роли атакующего:**
- при защитнике типа `Unknown` выбрасывает исключение `Can not resolve battle with unknown ship`;
- побеждает только `Флаг`;
- проигрывает `Камень`, `Бумага` и `Ножницы`;
- при столкновении с `Миной` обе фигуры уничтожаются;
- против другого `Скуат` — ничья;
- проигрывает `Универсал`, `Универсал` меняет тип на `скаут`.

### `UnknownKaNoBuFigure`

**Назначение:** скрытое представление фигуры, тип которой неизвестен наблюдающему игроку. Это не самостоятельная боевая фигура.

**Движение:** не может двигаться (`IsMoveable = false`); любой `MoveStep` недопустим.

**Результат боя в роли атакующего:**
всегда ничья (`null`). Реальный результат боя определяется настоящей фигурой на основном поле, а `Unknown` используется в копиях поля с ограниченной видимостью.
